MapMaker Web Map Auditor

Self-check for distributor and partner web maps against the General Cartographic Standards

Public items only. Paste an item ID (a1b2…), an arcgis.com/home/item.html?id=… URL, a viewer URL with webmap=, or a group ID to audit every public web map in the group.

This tool automates the mechanical parts of review. Guideline checks marked warn are heuristics — a map may pass review with warnings, and the standards note that maps should still be reviewed by an NGS or Esri cartographer before publication. Nothing here is a substitute for that.
